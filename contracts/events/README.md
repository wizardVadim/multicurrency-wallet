# Событие крупной операции

Создаётся для успешного пополнения, вывода или обмена,
если долларовый эквивалент суммы составляет от 1000 USD включительно.

Для обмена учитывается списываемая сумма; создаётся одно событие.
Деньги передаются целыми числами в минимальных единицах валюты.

Повторная доставка сохраняет исходные event_id и transaction_id.

|Field|Type|Value|
|-----|----|-----|
|schema_version|integer|Версия контракта, сначала `1`|
|event_id|string UUID|Идентификатор события|
|transaction_id|string UUID|Идентификатор денежной операции|
|user_id|string UUID|Пользователь|
|operation_type|string|`deposit`,`withdraw`,`exchange`|
|status|string|`succeeded`|
|amount_minor|integer, int64|Сумма; для обмена - списанная|
|currency|string|`USD`, `EUR`, `RUB`|
|units_per_usd|string decimal|Использованный курс исходной валюты за 1 USD|
|occurred_at|string RFC3339|Время операции в UTC|

Все поля обязательны.
Идентификаторы должны быть непустыми UUID.
amount_minor — положительное число в пределах int64.
units_per_usd — положительная десятичная строка; для USD — "1".
Курс фиксируется при оценке операции и сохраняется при повторной доставке.
Порог проверяется без предварительного округления долларового эквивалента.
Событие доступно для публикации только после успешного commit операции.
